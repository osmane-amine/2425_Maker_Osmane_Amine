# 2425_Maker_Osmane_Amine

The goal of this project is to build a force feedback Joystick with a customisable profile. We will be exploiting the magnetic moment of neodymium magnets in a controled magnetic field in order to generate this feedback.

## Gimbal

Here is the model for the gimbal joint we will be using : https://cad.onshape.com/documents/fe0f47e07581fed1dca3328e/w/da3309cb8828203906bf12b8/e/b2376c934fffcf416dfed12f?renderMode=0&uiState=681228ecbed2246642bb3d72

The angular position will be captured along the X and Y axis using two potentiometers fixed to the base (RK09K1130A6S).
